## 01_入力パラメータ

**Redshift 費用試算｜01_入力パラメータ**

| パラメータ | 単位 | 入力値 | 入力の意味 | 注意点・分類 |
| --- | --- | --- | --- | --- |
| Redshift種類 | 選択 | Provisioned | RA3 Provisioned または Serverless | RG/DC/DSの料金モデルは対象外 |
| Node Type | 選択 | ra3.xlplus | Provisioned用。復旧も同じ単価 | 最小node数、quota、restore可能構成は実確認 |
| 通常node数 | nodes | 2 | 通常clusterの課金node合計 | Multi-AZなら総課金node数を入力 |
| 月の日数 | days | 30 | GB-monthの時間按分に利用 | 実際の請求月へ変更 |
| 通常Provisioned稼働 | hours/month | 720 | 月の稼働時間 | 予約割引・Concurrency Scalingは含めない |
| 通常Serverless使用量 | RPU-hours/month | 1280 | 合計RPU-hour。例：8×160h | baseCapacity×暦時間と誤計算しない |
| データ容量 D | GB | 1024 | 圧縮後物理保存量。一定と仮定 | 論理表の行数やS3原本容量ではない |
| 日次変更率 c | 割合/日 | 0.05 | 物理blockが1日に更新される割合 | 【推定】SQL行更新率とは別。独立・均等更新 |
| 有料manual取得頻度 f | 回/日 | 1 | 標準manualとBackup管理manualの合成頻度 | 自動snapshot/標準RPを除く。0または1以上の整数 |
| 日次系保持 R | 日 | 35 | f×R世代を近似 | 0〜3653日。整数 |
| 月次保持 M | 世代 | 12 | 現在から30日ごと | 0〜120の整数。暦月日数を近似 |
| 年次保持 Y | 世代 | 7 | 現在から365日ごと | 0〜10の整数。全長期世代が揃った定常時 |
| 保存量の実測上書き | 月平均GB |  | 空欄=推定。数値0=実測0 | 同account/Region/型の有料snapshot全体の月平均 |
| AWS Backup併用 | 0/1 | 1 | 1=manualを計画管理 | 管理方法の選択。同じ保存実体を2回加算しない |
| 標準Cross-Region | 0/1 | 0 | 1=native copy経路を計上 | AWS Backup Copyではない。D07とcopy試験が前提 |
| コピー先Region | 固定選択 | ap-northeast-3 | 公式Osaka単価を使用 | 別Regionなら単価を再調査 |
| コピー先実測保存量 | 月平均GB |  | 空欄=元の有料manual容量と同等の仮定 | 先の自動/RP保存が有料なら合算実測量へ置換 |
| 転送対象取得頻度 | 回/日 | 3 | nativeで転送される全種類の合成頻度 | 自動/RP/manualを含む。1以上の整数 |
| 初回フル転送回数 | 回 | 0 | 0=定常月、1=初回copy | 年間では一度だけ加算 |
| 通常月間転送量実測 | GB transferred |  | 空欄=変更率から推定 | 初回フル分を除いた通常転送量 |
| Cross-account共有 | 0/1 | 0 | 1=manual共有を利用 | 共有のみは独立コピーではない |
| 別account追加運用費 | USD/month | 0 | 別資源の追加Compute/RMS等の見積入力 | 05_Restoreと同じ資源なら二重計上を避ける |
| Restore先種類 | 選択 | Provisioned | Provisioned または Serverless | 型間復旧の制約は事前確認 |
| Restore容量 | GB/回 | 1024 | 復旧先の保存容量 | 一般AWS BackupのGB復元料金は使わない |
| Restore回数 | 回/月 | 1 | 月次訓練の例 | 整数。障害発生確率を示すものではない |
| Restore先稼働時間 | hours/回 | 8 | 作成から検証・削除までの予算仮定 | AWS処理時間/RTOの保証ではない |
| Restore先node数 | nodes | 2 | Provisionedのみ | node種類はC6の単価 |
| Restore先RPU使用量 | RPU-hours/回 | 64 | Serverlessのみ、各回合計 | 利用見込みまたは実測RPU-hour |
| 追加有料CMK数 | keys | 1 | 本見積に帰属させる異なる鍵数 | 元/先/Vaultで同じ鍵を二重計上しない |
| 追加有料rotation数 | key versions | 0 | 課金対象の追加version数を合計 | 各鍵の最初の2rotation等、公式料金を参照 |
| 対称KMS API回数 | requests/month | 10000 | 課金対象対称APIの月回数 | 0.03 USD/10,000回を1回単価へ換算 |
| KMS無料枠の配賦 | requests/month | 0 | account共通枠から本用途へ配賦した数 | 自動で20,000を差引かず他用途と重複を防止 |
| その他関連費 | USD/month | 0 | CloudTrail/ログ/監視/NW等 | 初期0は未算入。必要範囲を別見積 |
| C案の独立S3保管量 | GB-month | 0 | 東京S3 Standardの原本/UNLOAD | Redshift snapshotではない。DDL等は別保護 |
| C案S3要求/転送等 | USD/month | 0 | request、転送、再ロード等の追加見積 | 保管費だけでC案の総額としない |
