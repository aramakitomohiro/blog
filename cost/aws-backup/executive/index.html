1. 要約

これまで Redshift・DynamoDB の「本体の料金」を整理してきましたが、AWS Backup でバックアップを管理すると、本体とは別にバックアップの料金がかかります。AWS Backup の料金は次の4つの足し算です。

  • ① 保管料金：保管しているバックアップの量（GB）× 1か月あたりの単価。月の平均保管量で計算されます。
  • ② 復元料金：バックアップから戻したデータ量（GB）× 単価。戻したときだけ発生します。
  • ③ リージョン間コピー：災害対策で別の地域（リージョン）へ送った量（GB）× 転送単価 ＋ 送り先での保管料金。
  • ④ その他：復元テスト（1件ごとの定額）、監査機能、コールド保管の早期削除料金など。

最も重要な点：DynamoDB のバックアップは毎回「まるごと（フルサイズ）」保存されるため、保存する件数がそのまま料金に効きます。長く保存するなら「コールド保管」で保管単価を約7割下げられますが、コールドは最低90日分の料金が必ずかかり、復元時は割高になります。

2. ウォーム保管とコールド保管の違い

ウォーム保管は「すぐ戻せる通常の保管場所」、コールド保管は「めったに使わない長期保管用の安い保管場所」です。バックアップは必ずウォームに作られ、設定した日数が過ぎるとコールドへ移り、保存期間が終わると削除されます。

項目（DynamoDB、東京）ウォームコールド違い
保管単価（1GB・1か月）0.114 USD0.0342 USDコールドはウォームの30%（約7割安い）
復元単価（1GB）0.171 USD0.228 USDコールドからの復元は約1.33倍
最低保管期間なし90日90日より前に消すと、残り日数分の保管料が請求される
別リージョンへのコピー可能不可コールドにあるバックアップはコピーできない
  • コールド保管を使えるのは一部の種類だけです：DynamoDB（AWS Backup の「高度な機能」を有効にした場合）、EBS、EFS、Timestream、SAP HANA on EC2、VMware など。Redshift のバックアップはコールド保管に対応していません。
  • AWS Backup の推奨は「ウォームに8日以上置いてからコールドへ移す」ことです。

3. 簡単な試算（説明用）

説明用の試算です。東京リージョン（ap-northeast-1）の AWS 公式価格表（Price List API、2026年10月8日取得）の単価を使用しています。金額は米ドル・税抜で、単価は変更される可能性があります。実際の見積もりは AWS Pricing Calculator と公式料金ページで確認してください。

前提：DynamoDB テーブル 1,000GB（1年間で増減なし）を毎日1回バックアップ。金額は AWS Pricing Calculator と同じ計算方法による「1年目の平均月額」です。

ケース保存のしかた月額（1年目の平均）
A30日保存（すべてウォーム）3,279 USD
B365日保存（すべてウォーム）20,805 USD
C365日保存（ウォーム90日 → コールド275日）12,569 USD

計算ツールには含まれない費用も、必要に応じて足します（同じ前提、説明用）。

追加の費用計算金額
1,000GB を1回復元（ウォームから）1,000GB × 0.171 USD171 USD／回
1,000GB を1回復元（コールドから）1,000GB × 0.228 USD228 USD／回
毎日のバックアップを大阪へコピー（転送料）1,000GB × 30回 × 0.11 USD3,300 USD／月
大阪での保管（30日保存、ケースAと同条件）計算ツールで大阪リージョンを別に見積もり約3,279 USD／月
改ざん防止の特別な保管庫（論理エアギャップ保管庫）保管単価が通常の約1.15倍ケースAなら約3,771 USD／月

※Redshift を同じ条件（1,000GB・30日）で計算ツールに入れると 719 USD／月と表示されます。ただし Redshift のスナップショットは実際には変更部分だけが増える方式で課金されるため、実額はこれより大幅に小さくなる可能性があります（技術者向け資料の8章を参照）。

4. 主なリスク

  • コールドの90日ルール：コールドに移したバックアップは最低90日分の保管料がかかります。保存期間を短く変えても、早期削除料金として残りの日数分が請求されます。
  • 復元料金：平時は0円でも、障害時に大量に復元すると「復元量 × 単価」が一度に発生します。コールドからの復元はさらに割高です。
  • リージョン間コピー：DynamoDB は毎回まるごとコピーされるため、毎日コピーすると転送料が保管料と同じくらいになることがあります。送り先での保管料も別にかかります。
  • 二重の保護：DynamoDB 本体の PITR（35日以内の任意時点に戻せる機能）と AWS Backup を両方使うと、両方に料金がかかります。必要な復旧要件に合わせてどちらか、または両方を選びます。
  • 計算ツールの対象外：AWS Pricing Calculator（AWS Backup）は保管料金だけを計算します。復元・転送・監査・特別な保管庫は手計算で足す必要があります。

5. 見積もりの進め方

  1. 現在のデータ量、1年間の増加率、1日の変更率、保存期間、コールドの使い方、コピーの有無、想定する復元量を集めます。
  2. AWS Pricing Calculator（AWS Backup・東京リージョン）に入力し、計算過程（Show calculations）を記録します。
  3. 同じ計算を手計算で再現し、計算ツールに含まれない費用（復元・コピー転送など）を足します。
  4. 両者を照合し、運用開始後は実際の請求（Cost Explorer）と比べて補正します。
